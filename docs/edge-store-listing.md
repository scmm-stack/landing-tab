## Privacy page

**Single purpose:** Replaces the new tab page with a dashboard of the user's own shortcuts, with search, a clock and wallpapers.

**Remote code:** No, I am not using remote code.

**Data usage:** No user data is collected.

**Privacy policy URL:** <https://github.com/scmm-stack/landing-tab/blob/main/PRIVACY.md>

**Permission justifications:**

| Permission | Justification |
| --- | --- |
| `storage` | Keeps the user's shortcuts, groups and settings in the browser. |
| `unlimitedStorage` | Keeps the user's own wallpapers and tile images, which can be up to 30 MB each, in the browser. |
| `activeTab` | Reads the current page's address and title when the user clicks the toolbar button, to add it as a shortcut. |
| `search` | Sends a query to the browser's default search engine when the user picks that engine. |
| `bookmarks` (optional) | Imports and exports bookmarks when the user asks. Requested at that moment. |
| Host access (optional) | Fetches a website's icon when the user adds a shortcut. Requested only if the user turns website images on, and can be handed back in Settings. |

## Description, English

Landing Tab turns your new tab page into a dashboard of your own shortcuts, and keeps everything on your device. There is no account, no sync, no analytics and no server.

- Organize shortcuts into groups in a sidebar, and drag them into order
- Show them as cards with an image, name and description, or as plain icons
- Search with built-in or custom engines, or your browser's default
- Add a clock and a full-screen standby page
- Use your own wallpapers with timed rotation, solid colors or animated scenes
- Add the current page from the toolbar button
- Import and export bookmarks
- Back up and restore everything through a file you keep

Website images are optional and need your permission once. They contact only the site you're adding, with no cookies and no referrer.

Available in English and Polish.

## Description, Polish

Landing Tab zamienia stronę nowej karty w pulpit z Twoimi skrótami i przechowuje wszystko na Twoim urządzeniu. Bez konta, synchronizacji, analityki i serwera.

- Układaj skróty w grupach na pasku bocznym i przeciągaj je w dowolnej kolejności
- Wyświetlaj je jako karty z obrazem, nazwą i opisem albo jako proste ikony
- Szukaj za pomocą wbudowanych lub własnych wyszukiwarek albo domyślnej wyszukiwarki przeglądarki
- Dodaj zegar i pełnoekranowy ekran czuwania
- Korzystaj z własnych tapet ze zmianą co określony czas, jednolitych kolorów lub animowanych scen
- Dodawaj bieżącą stronę przyciskiem na pasku narzędzi
- Importuj i eksportuj zakładki
- Twórz kopię zapasową i przywracaj wszystko z pliku, który zachowujesz u siebie

Obrazy witryn są opcjonalne i wymagają jednorazowej zgody. Łączą się tylko z dodawaną witryną, bez plików cookie i bez odsyłacza.

Dostępne po angielsku i po polsku.

## Notes for certification

Landing Tab replaces the new tab page. Open a new tab to see it. No account is needed. The toolbar button adds the current page as a shortcut. Website images are off until allowed, and Settings > Your data holds backup and bookmark tools.
